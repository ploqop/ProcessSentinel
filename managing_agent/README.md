# Process Sentinel Manager

Интерфейс управления для системы Process Sentinel. Позволяет управлять клиентскими агентами, просматривать логи и настраивать черный список процессов.

## Требования

- Node.js 14+ и npm
- Python сервер Process Sentinel

## Установка зависимостей

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

## Сборка для production

```bash
npm run build
```

Создает оптимизированную сборку в папке `build`.

## Функциональность

- Вход по логину/паролю менеджера
- Просмотр списка подключенных клиентских агентов
- Просмотр логов нарушений для каждого клиента
- Управление черным списком процессов

## Взаимодействие с API

Приложение работает с API сервера Process Sentinel. В режиме разработки запросы проксируются на http://localhost:8000 через настройку в package.json.
